# App assets

Drop your App Store Connect exports here. Recommended files:

```
apps/
  linkup/
    icon.png      # 1024x1024 app icon (or square logo)
    screenshot.png # optional hero screenshot for the project slide
  poker/
    icon.png
    screenshot.png
  remind/
    icon.png
    screenshot.png
```

**Best source:** App Store Connect → your app → App Information / Screenshots.

**Formats:** PNG or WebP. Square icons work best for notifications.

Once added, the portfolio will pick them up automatically from the paths in `src/data/projects/`.
